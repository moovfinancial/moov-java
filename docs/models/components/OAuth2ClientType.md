# OAuth2ClientType

The type of client requesting an OAuth2 token. Short codes are accepted as aliases for the corresponding client types.

## Example Usage

```java
import io.moov.sdk.models.components.OAuth2ClientType;

OAuth2ClientType value = OAuth2ClientType.WEB;
```
